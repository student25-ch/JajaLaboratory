## 📖 简介

Jajalaboratory 是一个基于终端的中文化学实验室模拟程序，尽量还原真实实验室中的：

- **器材约束**（量筒不能加热、烧杯需垫石棉网……）
- **药品性质**（钠保存在煤油中、镁条燃烧发白光……）
- **反应现象**（浮熔游响红、蓝色絮状沉淀……）

终端程序无法复刻 NB 实验室的 3D 视觉，但可以用规则系统与文字描述在逻辑层面做得像真的。

## ✨ 特性

### 🧪 真实器材约束（27+ 种器材）

| 约束类型 | 实现 |
|----------|------|
| 加热方式 | 不可加热 / 直接加热 / 需垫石棉网 |
| 反应容器 | 量器（量筒、天平）不能作反应容器 |
| 液面限制 | 试管加热液体不超过 1/3 |
| 固定方式 | 需铁架台、需坩埚钳等 |

### ⚗️ 药品库（36+ 种物质）

- 活泼金属：**Na**、Mg、Fe、Zn、Cu
- 酸碱盐：HCl、H₂SO₄、NaOH、Ca(OH)₂、Na₂CO₃、CuSO₄、AgNO₃……
- 氧化物：CuO、Fe₂O₃、MgO、Na₂O₂、P₂O₅
- 气体：O₂、H₂、CO₂
- 非金属：P、S、C

每种物质记录：状态、危险等级、密度、熔点、**保存介质**（如钠保存在煤油中）。

### 🔥 反应库（16+ 个反应）

| 类别 | 反应 |
|------|------|
| 气体制备 | 高锰酸钾制氧、氯酸钾制氧、H₂O₂ 制氧、石灰石制 CO₂、锌制 H₂ |
| **钠的化学** | 钠与水、钠在空气中加热、钠与硫酸铜溶液 |
| 金属置换/燃烧 | 铁置换铜、镁条燃烧、红磷燃烧、氢气还原氧化铜 |
| 酸碱沉淀 | 酸碱中和、AgCl 沉淀、NaOH+CuSO₄、氢氧爆鸣 |

### 🧂 钠的完整化学行为（重点）

NB 实验室中钠因为剧烈反应和免费使用成为梗，本项目完整实现其化学：

| 反应 | 真实现象（程序文字输出） |
|------|--------------------------|
| 钠与水 | 浮 → 熔 → 游 → 响 → 红 |
| 钠在空气中加热 | 先熔化 → 黄色火焰 → 生成**淡黄色** Na₂O₂（不是白色 Na₂O） |
| 钠与 CuSO₄ 溶液 | 先与水反应 → 气泡 → 蓝色絮状 Cu(OH)₂ → **不置换铜** |

额外规则：
- 钠必须用**镊子**取用，严禁用手
- 反应前必须**滤纸吸干煤油**
- 钠块过大时提示“可能爆炸”
